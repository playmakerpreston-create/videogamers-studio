# videogamers studio

Content system for the **@videogamers** Instagram page: an agent team, brand bible, style guide and slide renderer.

- **Start here:** `AGENTS.md` (Codex / ChatGPT) or `CLAUDE.md` (Claude Code)
- **Brand:** `brand/voice.md` · `brand/playbook.md` · `brand/style-guide.md`
- **Render a post:** `npm install && npx playwright install chromium && node tools/render.js output/<date>/<slug>/spec.json`
